FAQ

Got questions?

Everything you need to know about Prassu's Sheet.
How fast can I get started? ▼
Under 5 minutes. Create a Sheet, paste the ID, download the SDK, call login(). That's it.
Is it really free? ▼
Yes. No subscriptions, no hidden fees. Google Sheets provides the free tier. You only pay Google if you exceed their limits.
Which languages are supported? ▼
C++ (single-header), C# (single-file), Python (module). All three share the same API and backend.
What happens if I select No Bind Mode? ▼
If a license is set to No Bind mode, the security sub-engine bypasses device locking. The key can be shared and used globally across any workstation simultaneously.
Do I need to deploy a server? ▼
No. The backend is Google Apps Script — deploy once as a web app and you're done. No VPS, no database, no Docker.

Native C++ Framework

Include auth.h inside project path.

main.cpp
#include <iostream>
#include "auth.h"

int main() {
    std::string sid = "YOUR_ID";
    std::string app_ver = "1.0";
    std::string sv = gk_auth::checkUpdate(sid);
    
    if (!sv.empty() && sv != app_ver) {
        std::cout << "Update available: " << sv << "\n";
    }
    
    // System checks DB for local HWID lock match
    if (gk_auth::hwidLogin(sid)) {
        std::cout << "AUTO LOGIN SUCCESSFUL.\n";
        return 0;
    }
    
    std::string key;
    std::cout << "Enter License Key: ";
    std::getline(std::cin, key);
    
    if (gk_auth::licenseLogin(sid, key)) {
        std::cout << "ACCESS GRANTED.\n";
    } else {
        std::cout << "VALIDATION FAILURE.\n";
    }
    system("pause");
    return 0;
}

Managed .NET Framework

Inject managed auth.cs class directly.

Program.cs
using System;
using GkAuth;

string sid = "YOUR_ID";
string sv = Auth.CheckUpdate(sid);

if (!string.IsNullOrEmpty(sv) && sv != Auth.AppVersion)
    Console.WriteLine("Update: " + sv + " available");

// System checks DB for local HWID lock match
if (Auth.HwidLogin(sid)) {
    Console.WriteLine("AUTO ACCESS GRANTED");
    return;
}

Console.Write("Enter License Key: ");
string input = Console.ReadLine();

if (Auth.LicenseLogin(sid, input)) {
    Console.WriteLine("SUCCESSFULLY BOUND");
} else {
    Console.WriteLine("DENIED");
}

Python Core Logic

Requires standard requests module.

main.py
import sys
from auth import license_login, hwid_login, check_update, APP_VERSION

sid = "YOUR_ID"
sv = check_update(sid)
if sv and sv != APP_VERSION:
    print(f'Update: "{sv}" available')

# System checks DB for local HWID lock match
if hwid_login(sid):
    print("AUTO LOGGED IN VIA DB ENTRY")
    sys.exit(0)

token = input("Provide License Key: ")

if license_login(sid, token):
    print("LICENSE VERIFIED AND SESSION UNLOCKED")
else:
    print("REJECTED: VALIDATION FAILED")

Security Matrix

Authentication binding strategies explained.

HWID Lock (Hardware ID)

Locks the license exclusively to the user's operating system signature upon their first login. This ensures the key cannot be shared or used on another machine.

No Bind (Global Key)

Bypasses all hardware restrictions. The license acts as a universal token that can be freely authenticated from any workstation globally.
